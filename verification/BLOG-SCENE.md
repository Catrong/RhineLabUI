# 博客书架与空白纸阅读过渡

2026-09-17，本地 Chromium 浏览器验证。对应原生 TypeScript / Three.js 实现。

## 实现

- 删除旧四十份档案与 TXT，博客元信息和 Markdown 同时驱动列表、分类、三维书架与下载。分类、每类篇数可不同，位置映射不依赖原来五列八份。
- 交互池固定 288 个位置，按镜头附近循环补位并裁剪；参考对照保留 160 个位置。
- 默认性能画质，保存过的高画质或自定义配置不覆盖。
- 原卡片先竖直升到净空；抽页时间轴 0–0.65 秒拆开，0.65–1.75 秒从玻璃盖板下抽出，1.75–2.4 秒合闭，1.75–3.05 秒纸页移向正文区域，3.2 秒结束后创建正文。
- 纸页纯空白，没有标题、装饰线或正文。复用 Blender 信息基板几何及已有拆解资产。抽出后纸页在阵列前方移动；抽页期间隐藏场景渐变遮罩，避免遮住纸页。
- 目标位置读取实际阅读布局，按当前镜头反投影，并转正、缩放至目标范围。手机抽出期间镜头扩展取景，不横移原档案盒。
- 动画期间只有空布局占位，没有 `.blog-prose`。完成后才解析 Markdown 并创建正文。原始 Markdown 仍打包支持全文检索，不是延迟网络请求。
- 返回时取消旧动画，快速换页用请求版本隔离；正文创建后恢复滚动位置。减少动态效果和三维不可用直接阅读。

## 已验证

- `npm run check:content`：4 组内容测试、6 组场景/映射/时间轴/画质测试通过。
- `node --experimental-strip-types scripts/check-loop.mjs`：20,000 次方向移动、288 池与 160 参考位置通过。
- `npm run check:viewport` 与 `npm run build` 通过；构建仍有大包提示。
- 1440×900 和 390×844 视口：抽纸中间帧可见空白纸从档案盖板下伸出，未创建正文。
- 开发冻结 `?document-time=3.05`：桌面纸页投影 (473.33,148)–(1233.33,748)，手机 (22,314.67)–(352.67,793.67)，均与目标 DOMRect 对齐，数值误差小于 0.01px；纸页完整可见。该调试参数仅开发构建生效。
- 无冻结参数：直接文章地址与三维书架 READ ARTICLE 入口均在动画结束后进入可读正文；抽出期间取消能返回，随后可打开另一篇。
- 隔离测试服务 `node scripts/serve-blog-fixture.mjs`：160 篇、11 分类，分类篇数为 1/2/65/3/9/17/4/32/8/12/7。65 篇分类第 9 页正确显示最后一篇，选档序号 65/65，8 个滑动刻度；下一档循环回 1/65。实际渲染统计 logicalArticles=160、logicalCategories=11、instanceCapacity=288。
- 同一服务用 PowerShell `$env:BLOG_FIXTURE='empty'` 或 `'single'` 启动：空博客显示空状态、书架禁用读取与切换；单篇单分类左右与上下循环安全，实例池仍 288。测试未修改正式内容文件，服务已关闭。
- 新测试来源首次进入设置显示“性能”。减少动态效果打开后，从三维书架立即进入正文；既有 high 配置保持由自动测试确认。
- 常规浏览与空数据测试检查控制台无 error。
