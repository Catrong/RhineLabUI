# 博客改造验证

日期：2026-09-17。范围：普通网页博客入口、文章数据、查询与阅读，保留原生动画和三维档案体验。

## 自动检查

- `npm run check:blog`：4 组通过。覆盖文章短名与正文对应、站内文章链接、无效日期/重复短名/缺失字段拒绝、0 篇与 53 篇/7 分类的数据、正文搜索及分类/标签/收藏交集和日期排序。
- `npm run check:content`：原四十份档案和 TXT 导出一致性等 18 项通过。
- `npm run check:viewport`：原视口、参考画幅与渲染分辨率检查通过。
- `npm run build`：TypeScript、Vite 与 PWA 版本包生成通过。仍有主 JS 包超过 500 kB 的构建提示；本次保留 Three.js 主场景，不宣称已优化首屏下载量。

## 实现边界

- 原相机、模型、材质、时间轴和抽取/归位算法未改；本次检查未重复整个原视频逐帧叠加验收。
- 博客内容独立于四十份原档案；三维视觉选位复用原阵列，原档案体验仍使用自己的数据。
- 测试是桌面浏览器和视口模拟，不等于 iPhone Safari、Wallpaper Engine、线上 CDN 或 PWA 离线安装的实机验证。
- 文章和 CSS/JS 已包含在生成的 PWA 版本包；没有在本次执行离线安装和跨版本更新测试。
- 使用静态片段路由；不提供服务端逐篇 HTML、在线写作后台、评论或账号同步。详见 `docs/BLOG.md`。
- 未部署博客到原正式域名，也未修改 DNS。已有未跟踪的 `pnpm-lock.yaml` 不属于本次提交。
