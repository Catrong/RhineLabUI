# 文章纸张与 UI 连续过渡

2026-09-17。当前版本覆盖 BLOG-SCENE.md 中纯空白纸、移到正文位置并等待结束的旧流程。

## 当前行为

- 原独立返回按钮移入系统导航，紧邻 BLOG INDEX，显示 BLOG HOME。竖屏导航位于品牌下方，避免增加入口后重叠。
- 净空后玻璃在 0–0.65 秒逐渐透明，开盖与透明过程部分重叠；0.85 秒开始抽纸。
- 抽出和向下收起共用一个连续运动时钟。纸页完全离开盖板后才合盖；直线段与后续三次曲线使用匹配的切向速度，没有抽出后停顿。
- 纸面纹理显示标题、分类、摘要、作者、日期与阅读时间；长文本限行。复用既有 Blender 信息基板几何，没有新模型资产。
- 背景、文字和细线共用主题配色。主题变化时更新纹理；离开盒体后叠加后处理之后的共享几何通道，使纸色逐渐与 UI 色一致，避免 ACES 压黑纸张。
- 纸张向下收起到 handoff=0.25（时间轴约 2.08 秒）即通知博客创建正文，UI 从下方 36px 分组淡入（420ms，错峰 45ms）；此时纸张仍在移动。背景先过渡到 65% 不透明度，纸张退场结束后再恢复完整背景。
- 纸张继续收入实际屏幕下方，约 3.3 秒结束。正文在重叠期间只创建一次，不因动画完成重建，也不丢失滚动位置。
- 读文章、返回索引与三维书架包含 180ms 退出、320–420ms 进入。连续切换取消旧动画并按版本隔离；同页搜索不播放退场，保留输入焦点。减少动态效果直接显示。
- 扩展镜头取景以容纳纸页，UI 展开时平滑恢复原镜头。保持档案盒自身的竖直抽取规则。

## 抽出与回正衔接提速

档案达到原有 3.7 安全升起高度后即可启动纸张阶段，移除额外等待镜头 detail 到 0.9 的条件。玻璃清晰过渡缩为 450ms，开壳 80–480ms，纸张 500ms 开始抽出（原 850ms）；纸张移动本身仍为 2.3s，移除末端 150ms 空等，总纸张时间轴由 3.3s 缩到 2.8s。视角恢复从纸张下收 handoff=0.08 即开始，0.70 时目标已回正，不再等整段纸张动画完成；回正跟随速度提高并从当前镜头状态连续接续。保留纸张下收途中展开正文、跳过和取消逻辑。自动测试检查移动期间镜头已回正、原净空与清晰先于出纸等约束；未做浏览器验证。

最新衔接修订：纸张与拆解共用 80ms 起点，取消“拆解/玻璃完全展开后才出纸”的等待；玻璃变清晰、壳体展开和纸张初段抽出重叠进行，纸张运动仍保持连续 2.3s。纸张阶段总时长为 2.38s，视角随下收提前恢复的逻辑保留。自动测试断言起点两者均为零、下一时刻两者均开始运动，未做浏览器验证。
