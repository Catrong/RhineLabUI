# 书架点击、悬停与分类色

2026-09-17。按用户要求未进行浏览器验证。

- 指针释放时，只有原生输入逻辑判定为未拖动、未取消的点击才检测实体档案；命中当前物理选中位置调用打开文章，其他位置仍选档。同文章的其他循环副本不会误当成当前实体。
- READ ARTICLE 使用四条独立装饰线，按上（左到右）、右（上到下）、下（右到左）、左（下到上）顺时针依次伸展，每边 100ms；不改变按钮布局和命中区域。hover 与 focus-visible 均生效，减少动态效果关闭伸展过渡。
- 标题沿用滚动文字，首次出现 220ms 淡入。提示放在非缩放 DOM 层，使用实际命中实例、选中模型或归位模型的世界矩阵投影同一封面平面上的四角，复用 hudQuadMatrix 生成真正的透视变换。标题框左下角位于档案左边缘上方，宽度对应档案宽度；随镜头/升降更新，不再屏幕居中或夹紧位置。首次只淡入透明度，不叠加屏幕空间位移。拖动、模态窗口、阅读与退出悬停时隐藏。
- 技术为蓝色、设计为赭色、随笔为绿色；其他分类按名称生成稳定色相，文章排序变化不改变颜色。映射为 src/category-color.ts。
- 标签块复用 Index_Inlay 材质，通过实例 RGB 属性和独立模型 uniform 应用分类色；变化区间上传及静止复用失效条件已接入，固定模型池不增加。保留暗色主题和取消强调规则。

验证：TypeScript 通过；npm run check:content 的 4 组内容测试与 7 组场景测试通过，新增分类映射与两种材质 shader 注入/颜色 uniform 测试；npm run build 通过。构建仍有原有大包提示。shader 注入测试不等于真实 GPU 编译或视觉验收。

## 悬停标题字形排列修复

滚动库原先把投影后的字符包围框除以整体缩放值来求局部坐标，无法适配倾斜透视。悬停标题以 data-rn-local-layout 显式启用本地排版：使用测量容器内的 offsetLeft/offsetTop，并关闭由屏幕左边缘变化推导的位移补偿；字符尺寸继续使用原有本地尺寸补丁。整段文字只经外层四角矩阵投影一次，保留滚动动效，其他标题不变。补丁随 postinstall/prebuild 重现。按用户要求不进行浏览器验证。

后续开发环境修复：node_modules/.vite/deps/@kitlangton_rolling-number.js 实际仍包含旧屏幕坐标公式，未包含 data-rn-local-layout 分支，导致此前源码补丁没有进入正在运行的开发页面。Vite 现在将该原生 ESM 包排除出 optimizeDeps，直接服务已打补丁的源文件；配置变更触发开发服务重启，避免依赖锁文件不变时继续复用旧包。

序号修订：将同一局部坐标排版开关应用到档案序号、列编号、X- 后的三位档案编号及悬停编号。此前只开启悬停标题的修正，序号仍使用屏幕坐标测量；现在数字与标题一样先在本地排版，再接受外层透视，保留两位/三位格式及滚动动画。

## 取消与返回时旧详情闪现

博客实例初始化时添加持久 blog-app 标记，始终隐藏旧版 detail-ui（含黑条解密正文）。此前只在 blog-visible 时隐藏，取消抽取或返回书架时该类先被移除，旧详情退场尚未结束，因而短暂露出。新规则不依赖路由可见性或动画时序；保留三维抽取/归位和博客正文过渡，壁纸与独立参考模式不受影响。按要求仅做类型与构建验证，不进行浏览器验证。

## 抽取跳过入口

移除底部“正在打开 / 取消并返回”提示条，抽取时右上角显示 skip ▶▶（实心三角形）。点击完成当前纸张动画并显示文章，不返回列表；支持等待上一段归位时提前点击，正文显示后按钮随占位界面移除。保留键盘按钮语义、焦点样式和安全区边距。

导航显示时机：抽取阶段隐藏博客导航栏并保留布局占位，禁止指针与键盘访问；正文 reveal 时导航进入同一组淡入动画，skip 随抽取占位 DOM 被移除，另以非抽取状态 CSS 保证隐藏。减少动态效果时随正文直接显示。

悬停标题层级修订：标题挂到 three-scene 内，与画布同属场景层叠上下文，处于档案交互 UI、导航、页脚和弹窗下方；使用容器局部 CSS 像素投影，随舞台统一缩放，避免从 body 移入后重复应用屏幕缩放。保留四角透视与左边缘对齐。

## 悬停标题参与模型遮挡

最新要求覆盖此前 DOM 投影方案：改用运行时 Canvas 文字纹理面片，随实际命中档案的世界矩阵定位，与盖板共面、位于顶边上方且左边缘对齐。标题在主三维场景中渲染，启用 depthTest/depthWrite，不再有置顶 DOM 副本；前方档案参与遮挡，玻璃沿用现有透明材质渲染规则。标题跟随主题，首次淡入、切换时整段向上滚动，减少动态效果直接显示。纹理仅在内容、字体、主题或滚动进度变化时重绘；纹理版本、矩阵、可见性与淡入透明度由既有静止复用检测覆盖。字体监听与纹理/几何/材质随场景释放。

自动测试检查局部两角跟随世界矩阵、深度配置、静止不重绘、隐藏/淡入与监听释放；这不等于实际 GPU 遮挡或视觉验收，按用户要求未做浏览器验证。

## 标题整块升降与清晰度

最新改为单块标题从档案顶边升起、移开后落回（约 300ms，可从当前位置反向）；文字本身不滚动、不淡入。切换到其他档案时，旧标题先回收，随后新标题升起，同一时刻只有一块标题；回收继续跟随原物理档案。几何与 UV 裁切将顶边以下部分藏入档案，保留场景深度遮挡。文字纹理宽度从 1080 提升至 2160，使用 500 字重与设备支持范围内最高 16 倍各向异性过滤。移动不重新绘字，静止不重复上传 UV。减少动态效果直接到位。类型、场景测试与构建验证；未做浏览器验证。

## 跟手性与免景深标题

切换悬停档案立即接管单块标题，不再排队等待旧标题回收；离开时原位回收，再进入同一档案从当前高度反向。升降改为指数趋近（升起 26/s、回收 32/s，约 115ms/94ms 完成 95% 位移），起步立即响应、末端减速，不叠加慢起步曲线，保留减少动态效果直接切换。

标题单独使用 layer 31，从场景颜色、AO、景深及其他后处理输入中排除；后处理完成后仅在标题可见时重建屏幕深度（不写颜色），再绘制标题。因此文字不经过景深且继续接受真实几何深度遮挡，UI 仍在画布上层。该方案在显示标题时增加一次场景深度绘制与标题绘制；无标题时无额外通道。测试覆盖绘制次序、颜色保护、图层隔离以及正常/异常状态恢复；静止复用继续跟踪标题矩阵和纹理。未进行浏览器/GPU 视觉验证。


## 快速滚动补位、整排出现与 CPU 优化

- 实例窗口改为跟随实际轨道 columnCamera/rail，避免松手速度高于选档弹簧时窗口滞后，再突然切换位置。保持 9×32 共 288 个池位置；显式参考时间轴仍用原 160 个位置。
- 横排为同一 row 的 9 个列位置：用整排保守包围盒决定提交，不再对其中每份档案逐个剔除，选中/归位实体仍单独绘制。新补入成员共享本帧起点，220ms 平滑覆盖渐入，已存在成员不重播；坐标重基准按绝对逻辑位置保留进度。完全不可见的补位档案不接收实体点击。
- 渐入用同一实例属性和覆盖率抖动，不改变玻璃原有透明排序；主材质、阴影、AO 法线/共享深度、独立景深深度和清晰标题的遮挡深度均应用相同进度。减少动态效果与参考时间轴直接显示。无新增绘制通道；整排保留会比逐实例剔除提交更多边缘模型，这是整排完整性的取舍。
- 性能：跳过原本生成后未使用的候选网格/视锥高度切片；只在跨实际池边界时重建拓扑；同帧波浪结果缓存，零权重波浪不计算；复用行坐标缓冲，分类色直接写入共享属性，渐入属性仅上传变化范围，并使静止画面复用失效。
- Node CPU 辅助函数微基准（3000 帧、5 次中位数）旧可见范围准备+每帧拓扑 154.69ms，新准备+缓存拓扑 2.98ms。复现：`node --experimental-strip-types scripts/benchmark-archive-preparation.mjs`。只测这些辅助函数，未覆盖整帧、GPU、更多整排模型的成本，不能当作实际 FPS 提升。
- 验证：4 组内容测试、13 组场景测试与生产构建通过；新增大幅正/负位移、整排/288 唯一位置、拓扑复用、同排渐入/重基准、各材质 shader 注入和快速视锥等价性检查。既有大包提示保留。按用户要求未进行浏览器或 GPU 视觉验收。
