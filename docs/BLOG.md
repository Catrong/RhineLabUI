# 博客内容与维护

普通网页构建现在默认进入 **Rhine Journal · 莱茵手记**。原生开场、玻璃档案阵列、抽取与归位、独立模型查看器保留；右上「三维档案」可进入原交互。`?review=1`、逐帧对照和 Wallpaper Engine 构建仍沿用原路径。

## 写文章

1. 在 `content/posts.json` 添加元信息。
2. 在 `content/posts/<slug>.md` 写正文。
3. 执行 `npm run check:blog` 和 `npm run build`。

```json
{
  "slug": "my-first-post",
  "title": "我的第一篇文章",
  "description": "显示在列表和文章开头的摘要。",
  "category": "技术",
  "tags": ["笔记", "前端"],
  "date": "2026-09-17",
  "author": "你的名字",
  "featured": true
}
```

`featured` 可省略，其余字段必填。`tags` 可为空数组。日期为有效的 `YYYY-MM-DD`；短名只能使用小写英文、数字和单个连字符，必须唯一。标题可以修改，短名发布后应保持稳定。分类和标签从文章自动汇总，数量不限。空博客也能正常展示。

正文支持 GFM Markdown：标题、列表、引用、代码、表格、图片和链接。页面自动生成文章主标题，正文建议从 `##` 开始。代码可复制，代码块和宽表格独立横向滚动。HTML 经 DOMPurify 过滤，脚本、内联样式和表单不会执行。图片放在 `public/images`，使用 `/images/文件名.webp` 引用，并填写替代文字。

站内链接写作 `[文章名称](#/post/my-first-post)`。目录自动生成，阅读页的 `#section-1` 形式链接可跳转当前文章的章节。示例文章仅为演示用途，可全部替换；原 `content/archives.json` 留给三维档案体验，不用于博客索引。

## 阅读与查询

- 标题、摘要、作者、分类、标签和 Markdown 正文均参与不区分英文大小写的搜索；多个空格分隔的词须全部命中。
- 分类、标签、搜索、收藏条件取交集；支持最新、最早和标题排序，每页 8 篇。
- 条件保存在 URL，文章地址为 `#/post/<slug>`，可刷新、分享及使用浏览器前进/后退。当前会话内恢复各页面滚动位置。
- 长文提供目录、当前章节标记、阅读进度、字号、专注阅读、相邻文章和本机收藏。手机目录默认折叠，正文使用真实 CSS 像素，不随三维舞台缩小。
- 收藏和阅读偏好保存在本机浏览器；不提供账号同步。禁用存储时仍可浏览，偏好无法跨刷新保存。
- `/` 聚焦搜索，阅读时 `Esc` 返回列表；方向键、空格和滚轮保留原生阅读行为，不切换背景档案。
- 明暗主题沿用原场景配置。声音、减少动态效果、三维画质和 PWA 更新入口位于「三维档案 → 设置」。

## 动画与启动

从无片段的首页访问仍会显示原启动入口和完整开场（遵循原减少动态效果偏好）。带 `#/` 的链接直接进入博客，避免读文章时重复播放开场。「重播开场」可再次观看，结束后回到当前博客页面。

文章进入驱动原场景选档和抽取，回列表驱动归位；文章展示使用独立原生 DOM 阅读层。三维数组仍保留自己的五列四十档案，文章只选择一个视觉位置，不需要伪造文章来填满阵列。三维资源加载失败时仍显示博客。

## 构建与部署

```sh
npm ci
npm run dev
npm run check:blog
npm run build
```

输出为 `dist/`。内容校验已接入 `predev` 和 `prebuild`，校验不通过时阻止启动/构建。`npm run build:cloudflare` 仍输出 `release/cloudflare/site`。现有 PWA 将 Markdown 编译后的文章和 JS/CSS 一同纳入版本缓存，新增图片应按站点缓存策略配置；目前 `public/images` 不自动预缓存。

这是静态博客，无在线编辑后台、账号和评论服务。片段路由无需服务器路径重写，但不提供每篇文章独立的服务端 HTML、社交分享卡片或搜索引擎静态文章页；页面标题和摘要在浏览器中更新。若后续以 SEO 为主要目标，应增加预渲染与路径路由，而不是把当前客户端结果当作服务端输出。

独立 Novecento 字体仍遵循原授权和回退机制，不进入 Git。博客正文沿用 MiSans 字体。未修改原动画轨迹、相机、模型资产与授权部署环境。
